# Nabil Qureshi Personal Brand Website

Design-canvas source for **NabilQureshi.com**, imported from the Claude Design project
"Nabil Qureshi Personal Brand Website".

## Files

| File | Purpose |
| --- | --- |
| `Nabil Website.dc.html` | The full one-page site as a `.dc.html` design-canvas document (`<x-dc>` template + `DCLogic` component script). |
| `support.js` | Generated dc-runtime bundle that parses and renders the `.dc.html` document. |
| `image-slot.js` | `<image-slot>` custom element — user-fillable image placeholders used for the portrait and pillar photography. |
